# 用例 8 运行记录：已明确需要重新合并研究

用户输入：

> 请基于 PubMed 和可获得全文，重新合并南非醉茄对男性主观疲劳的研究。

任务已经明确为单数据库 Meta 证据合成，不再询问“审计已有 Meta，还是重新合并”。开始检索前先完善会改变结果解释的研究方案：

- P：男性的年龄、健康或疾病状态；
- I：南非醉茄制剂、剂量、疗程与是否允许复方；
- C：安慰剂、无干预或其他对照；
- O：主观疲劳量表、主要时间点与临床重要阈值；
- S：计划纳入的研究设计；
- 信息源：本例预先指定 PubMed，记录完整检索式、Query Translation、截止日期和全部命中；
- 全文：只从符合纳排标准且能够取得全文的研究提取数据，无法获得的全文单独列出；
- 分析：预先确定效应量、模型、异质性处理、敏感性分析和 GRADE 方法。

这种合成主要用于现有综述缺失、过时、方法不可靠，或新的研究可能改变旧结论的情况。它重新分析原始研究数据，而不是摘录一篇已有 Meta 的结论。

结果必须明确限定为“PubMed 中已识别且可获得全文的研究”。单数据库有漏检其他数据库研究和未发表研究的风险，因此不能称为全面系统综述或发表级 Meta；其价值在于以透明、可复核的方法，给出比随机挑选论文更可信的当前估计。

本机统计引擎探测结果：R 4.4.2 可用，但 `metafor` 不可用；Python 3.12.5 可用，因此选择 `native_python`。这只完成统计引擎选择，不代表研究方案、检索、筛选、提取或合并已经完成。
