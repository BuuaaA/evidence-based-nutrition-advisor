# 营养宣称与引用陷阱

## 常见外推

| 宣称套路 | 实际问题 |
|---|---|
| “人体必需成分，所以补得越多越好” | 生理需要不等于额外补充有效；基线缺乏状态决定收益 |
| “能吸收/能过血脑屏障，所以改善功能” | 暴露和靶点可达性不等于临床获益 |
| “动物实验显示致癌/延寿” | 物种、剂量和暴露路径可能无法外推到人类口服剂量 |
| “某指标提升 20%” | 指标可能是替代结局，绝对变化和实际意义可能很小 |
| “高质量期刊已经证明” | 期刊不能替代研究设计、偏倚和完整证据体评价 |
| “有 Meta 分析支持” | Meta 可能合并了不相容的人群、剂型或结局，也可能重复数据或遗漏阴性研究 |
| “医生都推荐” | 未说明指南、适用人群、推荐强度和批准适应证 |
| “一种成分无效/有害” | 可能把特定剂量、制剂或人群外推到整个成分类别 |

## 引用清洗

引用的论文真实存在，但不支持广告原句，常见方式包括：

- 引用综述的背景段落而非研究结果；
- 研究对象是缺乏者、患者或老年人，广告外推到所有健康成人；
- 研究使用处方级高剂量或专有原料，产品使用低剂量消费级原料；
- 研究测量实验室指标，广告改写成症状、疾病或长期健康获益；
- 使用事后亚组、次要结局或边界显著结果；
- 只引用单个早期阳性研究，忽略后续重复失败；
- 只报告相对变化，不给基线值、绝对效应或置信区间；
- 把“未发现显著风险”写成“已经证明绝对安全”。

## 产品迁移核查

对具体产品至少核对：每日实际摄入量、有效成分而非原料总重、化学形式/菌株/植物部位和提取标准、辅料或共干预、服用条件、第三方检测、污染/氧化/掺假风险、研究剂量与产品剂量的差距、达到研究剂量的每日成本。

结论必须说明：研究支持的是“成分概念”、某种研究原料，还是用户面前这个具体产品。
