# 低风险结构化个体试用协议

本协议处理一种窄场景：群体证据不足以支持常规采用，但也没有显示无重要效果或不可接受伤害，用户仍希望知道是否值得亲自试一段时间。目标是把不确定性变成有边界的个人决策，而不是降低循证标准、制造疗效承诺或为补剂销售背书。

## 1. 先分类证据状态

在讨论试用前，把关键结局归入以下之一：

1. **支持有意义获益**：按常规采用或条件性采用评估，不需要用试用掩盖已有结论。
2. **可能有小获益但不确定**：存在相关人体研究信号，但效应小、区间宽、不一致或对当前用户间接；可以进入试用准入评估。
3. **尚不足以判断**：相关人体证据很少或关键结局缺失；只有在风险很低且可测量时，才进入准入评估。
4. **证据显示无重要效果**：可信证据已排除用户在意的最小有意义获益；判为 `not_worth`，不以“也许你是例外”改写为 `trial`。
5. **证据提示有害**：伤害、相互作用或产品风险超过潜在获益；判为 `avoid`。

机制、动物、体外、病例或产品营销只能提供假设，不能单独满足“相关人体信号”。若普通功效检索或筛查不完整，使用 `insufficient`，不能把流程缺口包装为试用理由。

## 2. 四道准入门

只有四道门全部通过，才使用 `trial`。

### A. 证据信号门

- 至少存在与目标结局相关的人体数据，或目标是纠正有合理依据的摄入不足；
- 未有较可信证据显示无重要效果；
- 不是仅凭机制、网红体验或相邻成分外推；
- 计划使用的剂型、剂量和产品与证据信号不过度脱节。

### B. 安全门

- 症状轻至中度、相对稳定，没有需要先评估的红旗；
- 干预在拟用剂量和时限内风险低、可逆；
- 已核对总摄入、耐受上限、药物和补剂相互作用、孕哺、肝肾功能、手术及相关疾病；
- 产品成分、剂量和质量可核验，避免专有混合物、超剂量、多成分堆叠和来源不明产品；
- 试用不会延误必要诊断、正规治疗或更直接的生活方式干预。

### C. 可测量门

- 只选择一个主要目标，例如入睡潜伏期、夜间醒来次数、主观疲劳量表或训练表现；
- 先记录足够的基线，结局可重复观察，不用“整体感觉更好了”作为唯一标准；
- 预先定义最小有意义改善、评估时间点和不良事件；
- 预期起效和停用后的变化能在现实时间窗内观察。长期疾病结局、极少发生事件或需要多年累积的结局不适合个人试用判断。

### D. 可执行门

- 一次只改变一个主要干预；
- 剂量、用法、产品和时限固定，依从性可记录；
- 尽量保持睡眠、咖啡因、酒精、训练、核心饮食和药物稳定，并记录不可避免的变化；
- 成本和负担可接受；
- 有清晰停止规则，且用户愿意在结论不支持时停用。

任一道门未通过，就输出“仅在条件满足时考虑”“暂不值得”或“不建议自行使用”，并指出未通过的门；不要用模糊的“因人而异”。

## 3. 两种试用名称

### 结构化个体试用（默认）

前瞻性记录一次干预前后变化，适合普通用户的现实决策。它能帮助判断“我是否愿意继续”，但容易受自然波动、期待效应、回归均值和同期变化影响，不能自动证明因果。

### N-of-1 试验（严格使用）

只有方案包含同一人的重复交叉周期，通常还有随机次序、盲法或匹配安慰剂，并合理处理洗脱期和携带效应时，才称为 N-of-1。它只适合相对稳定、可逆、起效和消退较快的症状与干预。不可逆干预、长潜伏期、持续累积效应、急性危险状态或无法洗脱的干预不适合。

不要把一次“吃两周看看”称为 N-of-1。

## 4. 必须输出的最小方案

当判定为 `trial` 时，回答和 HTML 必须包含：

- **类型**：结构化个体试用，或满足严格条件的 N-of-1；
- **目标**：一个主要症状或功能结局；
- **基线**：试用前如何记录以及记录多久；
- **方案**：单一产品、剂量、频率、时限和依从性记录；
- **结局测量**：量表、日记、设备或可重复的功能指标；
- **成功规则**：预先定义的最小有意义改善，以及改善需持续多久；
- **停止规则**：不良反应、症状恶化、无效截止点、红旗或需要就医的条件；
- **混杂控制**：需尽量保持稳定并记录的关键因素；
- **到期动作**：达到阈值可讨论继续；未达到就停用，不用沉没成本延长。

不虚构精确的个人获益概率。若没有可靠数据，不说“你有 60% 概率有效”；改为说明证据状态、试用成本和如何减少误判。

## 5. 解释试用结果

- 个人改善与群体平均效应不冲突，但也不推翻群体证据；它只改变当前用户是否继续的决策。
- 单次前后改善可能来自期待效应、自然波动、回归均值、同时改变的行为或测量误差。
- 未达到预设阈值时默认停止，不以“可能需要更久”无限延长；若合理起效时间本来更长，应在开始前写入方案。
- 出现不良反应、红旗或与药物治疗冲突时立即停止并按风险程度寻求专业帮助。
- 若用户希望提高因果可信度，且干预适合重复交叉，再升级为真正的 N-of-1 设计；否则诚实保留不确定性。

## 6. 受控结论映射

| 判定 | 何时使用 |
|---|---|
| `priority` | 有较可靠、对用户直接且有意义的净获益 |
| `conditional` | 仅在缺乏、特定疾病、人群、剂型或监督条件下值得 |
| `trial` | 群体证据不确定，但四道门全部通过且已生成完整试用方案 |
| `not_worth` | 无重要效果、预期收益过小、不可测量、成本负担不值或替代路径明显更优 |
| `avoid` | 有害、相互作用、红旗、需医学监督或可能延误治疗 |
| `insufficient` | 检索、筛查或关键证据边界尚不足以可靠裁决；不是自动试用许可 |
