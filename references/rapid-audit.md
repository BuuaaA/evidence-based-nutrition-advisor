# 快速与专业证据审计

本流程同时规定 L1-Quick 的声称边界和 L1-Audited 的完整审计方法。目标是先给普通用户可行动且可追溯的判断，再按风险或明确请求升级；快速卡不得冒充系统综述，完整审计也不得阻塞快速卡。

## 1. 模糊问题与最小必要信息

普通用户常用“鱼油改善血脂吗”“氨糖对关节痛有用吗”这类宽问题开场。不要要求用户先把问题写成 PICOS，也不要默认发送年龄、性别、病史和用药清单。

先区分两种意图：

- **一般证据问题**：用户只问某干预通常有没有用。按清楚写明的常见情境直接回答，不读取档案，不追问个人资料。
- **个人决策问题或意图不明**：若缺失信息会改变个人建议，在完整检索和答案生成前先完成一次点击式关键信息收集；用户跳过时，再按明确写出的常见情境交付一般证据。交互方式见 `pre-evidence-intake.md`。

### 决策翻转测试

在提问前，先形成暂定判定，并对每个缺失变量模拟不同答案。只有该变量会导致以下任一变化时才询问：

1. 购买或使用判定发生变化；
2. 应采用的证据人群、干预形式或结局发生变化；
3. 安全红线或相互作用发生变化；
4. 需要从自我照护转为医学评估。

从通过测试的变量中，选择信息价值最高且最容易回答的项目，通常 3–5 个，硬上限 5 个。若只有 1–2 个变量真正通过测试，就只问 1–2 个，不为凑数收集背景资料。优先问具体目标、诊断、关键化验、剂型/剂量和相关用药；不要把年龄、性别当作固定入口。如果绝经状态、孕哺、年龄层或性别确实改变证据适用性或安全性，直接询问那个具体状态。

问题应提供可点击的互斥选项和“不清楚”，并简要说明它会改变什么。例如：“你主要异常的是甘油三酯还是 LDL？这会决定鱼油是否对准目标。”不要问不会改变建议的背景资料，也不要重复询问当前对话或已启用档案中有日期且仍可用的信息。

关键答案提交后再确定最终问题范围并生成证据。用户选择跳过或“不清楚”时，仍可给一般证据底线和安全提醒，但必须把暂定情境与匹配度未知写清楚。若出现需要立即处理的安全信号，先给安全提醒，不等待问卷。

| 模糊问题 | 关键信息维度（按决策翻转测试取舍） | 为什么会改变建议 |
|---|---|---|
| 鱼油能改善血脂吗？ | 目标血脂分项；最近甘油三酯档位；降脂/抗凝用药；计划使用的产品类型 | 甘油三酯、LDL、处方 EPA 与普通鱼油不是同一问题，用药会改变安全和替代治疗边界 |
| 氨糖软骨素能缓解关节疼痛吗？ | 疼痛关节；是否确诊骨关节炎；红肿发热/外伤等警示；相关用药；产品成分与剂量 | 研究主要针对特定骨关节炎，不能外推到所有关节痛，部分症状需要先就医 |
| 老年人有必要吃钙片吗？ | 骨质疏松/脆性骨折状态；饮食钙摄入；肾病或结石；维生素 D/相关用药；生活或机构养老情境 | 收益取决于缺口和骨折风险，肾病、结石与共用药会改变剂量和安全边界 |

## 2. 先形成问题地图

当用户从症状或状态出发时：

1. 提取目标结局，例如入睡时间、总睡眠时长、白天警觉、甘油三酯、LDL-C、记忆测验或主观精力。
2. 区分用户已知原因、可能原因和需优先排查的安全或医学警示信号；不要把所有状态默认解释为营养缺乏。
3. 生成有限的候选路径：检查/缺乏纠正、食物或饮食路径、营养补充、医学评估。
4. 若用户已给候选组合，先排序，不逐项平均用力。

优先深入那些同时满足以下条件的项目：可能有实质获益、与目标直接、证据较可靠、安全性可接受、结果会改变购买决策。

## 3. 把宣称拆成证据链

| 环节 | 问题 | 可支持它的证据 |
|---|---|---|
| 生物学合理性 | 该成分是否参与相关生理过程？ | 生化、体外、动物、遗传或病理生理研究 |
| 暴露与代谢 | 口服后吸收什么、代谢成什么、暴露量多少？ | 人体药代、示踪或生物利用度研究 |
| 靶点可达性 | 原形成分或活性代谢物是否到达目标组织？ | 人体组织、脑脊液、成像或可信靶点指标 |
| 临床效果 | 对用户真正关心的结局是否改善？ | 直接人体 RCT、可信系统综述、指南证据表 |
| 产品可迁移性 | 当前产品与研究干预是否相同？ | 原料、剂型、剂量、纯度、辅料、用法和检测资料 |

每个结论只停留在证据实际到达的层级。不得用“人体必需成分”“能通过血脑屏障”直接推出“口服后改善记忆”。

## 4. 取证顺序

### 4.1 指南与权威建议

先检索与目标人群、结局和用途相符的最新指南或正式立场文件。记录发布机构、年份、目标人群、剂量/制剂、推荐强度、证据等级、检索截止日期和利益冲突。

指南只负责回答“组织建议什么”；不能仅因来自某国或某著名学会就视为正确。质量判断见 `evidence-appraisal.md`。

### 4.2 现有证据合成作为历史基座

寻找近期系统综述、Cochrane 综述或指南证据综述。优先能提供：预注册、完整检索、纳入研究列表、偏倚风险、效应量与置信区间、异质性、资金来源和 GRADE 的来源。它承担历史证据基座的角色，不是“找到一篇综述就停止”。

对候选基座至少记录：完整 PICOS、检索数据库、检索截止日期、纳入研究、关键方法缺陷、结局级效应与确定性。基座不可信或与目标问题不匹配时，说明为何不用，并进入从头 PubMed 快速证据普查。

### 4.3 L1-Quick 最低来源核验

缓存未命中、过期或范围不匹配时，不同步进入全量 PubMed 主路径。先在 60–90 秒预算内核验三类来源：与用户地区匹配的 DRIs/指南/监管标准、一份方法可靠的指南或系统综述、一份权威安全资料。记录每个来源的角色、核验日期和它实际支持的结论。

L1-Quick 只允许给受控、可修订的快速判定。输出必须显示覆盖范围、仍不确定的结局、什么会改变建议和完整审计计划；确定性写“快速核验，未正式评级”。不得使用“全量筛查”“完整审计”“系统综述”“快速 GRADE”或“暂定 GRADE”等标签。达到时间预算时停止扩展并交付当前状态；若三类来源尚不齐全，退回 L0-Safety 或标为快速核验中/覆盖受限。

### 4.4 可复现 PubMed 审计（仅 L1-Audited 或 L2）

先按 `fast-path.md` 校验本地证据包。新鲜且范围直接匹配的证据包代表一次已经完成的可复现审计，不重复检索。只有缓存缺失、过期、无效、超出范围，或用户明确要求最新/深度审计时，才在本轮完成可复现 PubMed 检索：

- 有合格历史基座或过期证据包：从 `last_search_end` 次日开始更新检索，完整筛查全部新增命中；同时核查是否出现新的系统综述、RCT、重要安全信号或撤稿/更正。不得重复筛查历史记录。
- 没有合格历史基座的普通 L1-Audited：对内部定义且范围可管理的 PICOS，默认检索最近 10 年并完整筛查这个时间窗内的全部命中。证据护照必须写“近 10 年范围内完整”，不得简写成“全历史完整”。
- L2-Research，或用户明确要求“全库、全时间、不限年份、全部历史”等范围：使用全时间检索。若命中超过稳定导出边界，按日期分段并核对去重。
- 近期可信系统综述及其参考文献可用于识别 10 年以前的关键研究和历史背景，但不能把参考文献追踪冒充从头完成的全历史筛查。
- 结果过宽：先缩窄结局、剂型、产品、人群或研究设计。不得为赶时间静默截取前 N 条；若仍无法全量筛查，输出必须标为初步或“暂不能可靠判断”。

PubMed 查询至少包含：

- 已核实的 MeSH/主题词（存在时）；以及
- 题名摘要自由词：通用名、拼写变体、化学名、拉丁学名、提取物/菌株/盐型/剂型和研究原料名。

禁止 MeSH-only。新近和未完成 MEDLINE 索引的记录可能没有 MeSH；仅使用出版类型标签也可能漏掉未索引的系统综述。

检索概念块以高召回为目标。不要机械加入对照或结局词导致漏检；是否加入研究设计过滤器取决于题目和是否使用经过验证的高敏感度过滤器。正式运行前核实 MeSH、拼写变体、原料/剂型/盐型、产品名和研究专用名。

示意结构：

```text
("Controlled term"[mh] OR synonym1[tiab] OR synonym2[tiab] OR formulation[tiab])
AND
("Systematic Review"[pt] OR systematic review[tiab] OR meta-analy*[tiab])
```

正式搜索前查看 PubMed Search Details/Query Translation。不要照抄示意词作为未经验证的最终策略。

使用：

```powershell
python scripts/pubmed_search.py --query "完整检索式" --since-years 10 --out hits.ris --manifest search-manifest.json
python scripts/pubmed_search.py --query "更新检索式" --date-from 2024-06-01 --out update.ris --manifest update-manifest.json
python scripts/pubmed_search.py --query "研究级全历史检索式" --all-years --out all-years.ris --manifest all-years-manifest.json
```

脚本未指定时间参数时默认最近 10 年；也可显式使用 `--date-from` 或 `--all-years`。它在选定时间范围内默认导出全部命中并保存 Query Translation、时间范围、命中数、导出数、完整性和 RIS 散列。只有明确使用 `--allow-truncated` 才能截断；截断结果不得生成通常的确定性结论。

导出同时保留 PubMed 提供的出版类型与 PMCID。随后用 `scripts/ris_screening_draft.py` 生成筛查 CSV；其中的 `screening_priority` 和 `triage_hints` 只用于安排阅读顺序，不是纳排决定。所有记录仍须完成题名摘要筛查，自动提示不得写入最终排除理由。

### 4.5 全量筛查和纳排记录

对检索导出的每条记录完成题名摘要筛查；达到全文评估条件的记录应获取全文。先完整读取 `full-text-access.md`：PubMed 摘要页没有全文按钮不等于全文不可得，必须跟随 PMCID、DOI/出版社和适当的合法开放仓储。可批量生成候选入口并并行核查，避免单个站点超时串行阻塞。快速流程允许单人完成，但必须披露。使用 `templates/rapid-screening-log.csv` 保存：

- PMID/DOI、题名、年份；
- 题名摘要判定与理由；
- 全文状态；
- 全文访问候选、实际尝试入口与核查日期；
- 全文纳入/排除和预定义理由；
- 同一研究的多篇报告标识；
- 对应关键结局和研究设计。

交付前核对以下计数关系：命中数 ≥ 导出数 ≥ 题录筛查数 ≥ 全文评估数 ≥ 纳入报告数 ≥ 纳入研究数。声称“完整导出”时命中数必须等于导出数；声称“完整筛查”时导出数必须等于题录筛查数。报告主要全文排除原因及数量，不需要把每条排除记录塞进第一屏。

系统综述基座中的历史研究与更新检索命中的报告要按“研究”去重，不能把综述汇总值和其中单项试验再次作为相互独立的证据重复计算。

### 4.6 安全信息

安全性优先参考监管机构、权威卫生机构、药品说明、相互作用数据库、长期试验和系统综述。短期有效性 RCT 没有发现严重不良事件，不等于长期安全。

## 5. 冲突裁决顺序

文献或指南冲突时依次检查：

1. 人群和基线营养状态；
2. 干预剂型、剂量、配方和共干预；
3. 对照；
4. 结局是替代指标还是真实获益；
5. 随访时长；
6. 研究设计和偏倚风险；
7. 检索截止日期；
8. 效应量是否小到不具决策意义；
9. 指南采用的价值、成本、阈值与当地批准状态；
10. 利益冲突和选择性引用。

如果冲突能由上述差异解释，直接说明各结论分别在什么条件下成立，并用四列裁决表展示：**来源及结论 / 为何不同 / 方法或适用性局限 / 本次决策权重**。权重是透明的定性判断，不是把检查项相加得到的质量分。

不要为了展示裁决而制造冲突。来源一致时，说明一致到哪个结局、为何最佳来源足以主导结论，以及仍剩下什么不确定性。只有近似同一 PICOS 的可信来源仍真正冲突且会改变决策时，才建议研究级升级。

## 6. 分开输出三层判断

1. **证据体确定性**：针对每个关键结局，综合全部相关研究评价效应估计有多可信。GRADE 属于这一层，而且不是给单篇论文打分。
2. **当前用户匹配度**：用户与证据在 P/I/C/O、基线状态、剂型、剂量和随访上的相似程度。匹配度未知或较低，不代表原研究质量变差。
3. **决策价值**：结合效果上限、风险、成本、可行性、替代路径和用户目标，判断是否值得采用。

可以出现“证据确定性中等，但当前用户匹配度未知”，也可以出现“证据确定性较高，但效应太小、决策价值低”。不得压缩成一个含义不清的“证据等级”。

## 7. GRADE 路由

GRADE 只适用于已进入 L1-Audited 或 L2 且证据体边界满足相应门槛的任务。L1-Quick 明确不做正式或暂定 GRADE。审计完成后按以下顺序选择，并在交付中明确写出路径：

1. **引用已有 GRADE**：最佳可信综述或指南已针对匹配结局评级；核查其方法、PICO、检索截止日期和更新研究后引用。
2. **基于快速证据综合的 GRADE 评级**：没有可直接采用的评级，但已识别证据体并满足 `grade-methodology.md` 的最低条件。逐结局评价全部相关域，记录升降级脚注，披露数据库、全文、语言、单人评价等快速流程简化。
3. **基于当前可得证据的暂定 GRADE**：全部命中已导出、题名摘要已筛完、证据体边界可识别，但部分候选全文无法取得。等级必须带“暂定”，列出缺失全文数量与记录，把无法判断的域按不确定性处理，并提示用户上传全文后重评。
4. **GRADE-informed 快速确定性判断**：检索被截断、题录筛查未完成、证据体边界不清或关键效应信息缺失。说明可能的问题和资料缺口，不声称完成 GRADE。

审计中的 GRADE 可以基于叙述合成，不要求必须完成 Meta。反过来，有森林图也不代表具备 GRADE 条件。证据识别范围和所有域的显式判断不能被省略。

对于普通功效问题，自行实施快速或暂定 GRADE 还要求：PubMed 命中已完整导出并完成题名摘要筛查，或可信历史基座之后的 PubMed 更新命中已完整导出并完成题名摘要筛查。全文全部取得且五域可判断时使用正式快速 GRADE；部分候选全文不可得但证据体边界和关键效应可识别时使用暂定 GRADE；其余情况使用 GRADE-informed，确定性栏写“无法正式评级”。

新完成的快速 GRADE 至少交付：结局、效应估计或叙述结果、四级确定性、各域判断及升降级理由、证据检索/更新日期、流程简化和限制。详细操作读取 `grade-methodology.md`。

## 8. 停止条件

### L1-Quick 停止条件

- 三类最低来源已经核验并记录日期与角色；
- 已能给安全边界、受控判定、覆盖范围和不确定性；
- 已写清完整审计继续、暂停或仅按明确请求进行；
- 或 90 秒预算已到，此时按实际状态交付，不继续扩展快速路径。

### L1-Audited 停止条件

满足以下条件即可交付，不继续堆文献：

- 已找到与目标问题直接匹配且方法可信的最新指南或系统综述；
- 已保存可复现 PubMed 检索记录，全部命中已导出并完成筛查；更新检索未发现明显改变结论的新证据；
- 已记录 PICOS 纳排标准、筛选计数、主要排除原因和历史基座；
- 已能按关键结局给出效应量级和证据体确定性，并分开说明用户匹配度、决策价值与安全提示；
- 新增文献只重复现有结论，不再改变用户决策。

如果 PubMed 不可访问、检索被截断或题录筛查未完成，明确标注限制，不补写不存在的数据，也不输出四级确定性结论。若仅是部分全文不可得且符合暂定 GRADE 条件，可以继续评级，但必须使用“暂定”前缀、显示缺失记录并请求用户上传全文。
