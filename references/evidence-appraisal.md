# 证据来源评价与冲突裁决

本文件用于快速、透明地判断来源是否适合当前问题，以及完整审计中如何记录来源评价。EAL 是本 Skill 的主要证据分析框架；按来源类型使用相应工具：研究与综述可使用适用版本的 QCC，指南需做专门的方法学检查。来源级快速检查不冒充完整 QCC、AGREE II、AMSTAR 2、ROBIS 或 RoB 2。QCC 与 EAL 结论评价规则见 `eal-methodology.md`。

## 1. 按来源角色评价

### 指南或立场文件

快速检查：

- 目标人群、问题、干预和结局是否与用户匹配；
- 证据检索方法和截止日期是否透明；
- 推荐是否能追溯到证据表；
- 是否区分证据确定性与推荐强度；
- 更新机制是否清楚；
- 专家组构成、患者价值和适用性是否被考虑；
- 资助与利益冲突是否披露并管理。

参考 AGREE II 的范围与目的、开发严谨性、适用性和编辑独立性。快速模式不得声称完成正式 AGREE II 评分。

完整审计时，指南检查作为独立记录，至少说明开发方法、证据到推荐的可追溯性、适用性、更新和利益冲突管理。不得用研究或综述的 QCC 表单给整份指南打分，也不得把指南自身的证据评级直接当作本 Skill 的 EAL 结论等级。

### 系统综述或 Meta 分析

优先检查 AMSTAR 2/ROBIS 的关键问题：

- 是否有预先方案；
- 检索是否与声称的范围相称；
- 纳排与筛选是否透明；
- 是否列出研究并避免重复数据；
- 是否使用合适的偏倚风险工具；
- 合并方法是否适合数据和研究设计；
- 是否解释异质性；
- 是否考虑小研究、传播偏倚与资金来源；
- 结论是否考虑原始研究偏倚和证据确定性。

不要把条目机械相加为“质量分”。一个关键缺陷可能使漂亮的森林图不可信。

完整审计时，对系统综述或 Meta 使用与该综述类型相匹配的 Review Articles QCC；如用 AMSTAR 2 或 ROBIS 作辅助，应单独标明工具和结果。不能把原始研究的 QCC 结果当作综述质量，也不能因综述或 Meta 的发表类型、新近程度或显著结果而默认其可信。

### 随机试验

快速检查随机化和分配隐藏、盲法与结局主观性、缺失数据、预注册结局、样本量与置信区间、依从性、随访时间、资金和分析是否为预设。单个阳性小试验不能覆盖完整证据体。

### 观察性、机制、动物和体外研究

观察性研究可提示关联和长期安全信号，但易受适应证、健康行为和残余混杂影响。机制、动物和体外研究只支持合理性或信号，不直接证明普通人口服后的临床效果。

## 2. 期刊与出版警示信号

期刊声誉不是证据等级。以下情况属于需进一步核查的异常信号，但不能替代方法评价：

- 撤稿、重大勘误或数据完整性争议；
- 无透明同行评议或疑似掠夺性出版；
- 异常短审稿、夸张标题或结论与数据明显不符；
- 作者、编辑、产品公司和资金关系未披露；
- 只有新闻稿、会议摘要或无法核对的二手引用。

高影响力期刊不能抵消方法缺陷；低影响力期刊也不自动判为不可信。

## 3. 证据体、用户匹配与决策价值分离

不要用一个“证据等级”同时表达研究质量、个人适用性和是否值得购买。

### 证据与结论支持状态

对单项研究/综述，使用与设计和资料类型相适配的质量工具记录具体偏倚与限制。长期观察研究能回答长期暴露、预后或罕见伤害问题；前瞻/回顾队列标签本身不能决定质量。评价混杂、测量误差、选择、时间顺序和结局确认。干预试验也要按盲法可行性及结局主客观性判断，不能以无法双盲自动判差。

对每个结局，记录直接证据支持什么、效应方向与大小、资料完整度、研究间一致性、临床影响、适用人群和限制。完成证据体界定与 EAL 结论评价条件后，使用 EAL I–V 并注明手册/表格版本；条件未满足时等级留空，明确标记未评估、初步、资料不完整或方法规则待核定。EAL V 只用于本轮没有直接支持或反驳该结论的证据可供评价，不代替流程未完成或全文未取得。

QCC 是来源质量评价；EAL 结论等级评价的是证据对具体结论的支持程度；效果方向和行动建议另行记录。不得把这些概念合并成一个“证据等级”。可转述来源已有的其他框架评级，但须注明原框架、结局、范围、日期和本轮核验情况；不得把既有 GRADE 数字换算成 EAL I–V。

### 快速来源采纳角色

快速核查对每个候选来源记录一个当前用途角色，并写明可核查的理由：

| 角色 | 用途 | 记录要求 |
|---|---|---|
| `primary_support` | 与问题直接匹配，且快速检查未发现足以排除其作为主要依据的缺陷 | 说明匹配点、已检查的质量信号，以及尚未核实的局限；这不等于完成完整 QCC 或证明高质量 |
| `context_only` | 可帮助解释背景、机制、实践现状或证据边界，但不足以支撑主要效果结论 | 指明其背景用途及不能支撑主结论的原因 |
| `not_relied_on` | 发现明显不匹配、重大方法问题、撤稿/更正风险或无法核实的关键缺陷 | 记录排除或降权理由和核查依据；不得只写“质量差” |
| `pending` | 资料不足，关键检查尚未完成，暂不能判断是否采纳 | 写明待核实项目；在解决前不得作为确定性结论的唯一支撑 |

以上是快速核查的来源使用角色，不是质量等级。角色应针对当前问题和具体结局；同一来源可支持一个结局、对另一个结局仅作背景。若需要完整审计，按适用表单完成逐项评价，不能把快速角色自动转换为 QCC 符号。

### 条目、定位与评价充分性

完整 QCC 逐项保存所用表单名称、版本及适用对象，并对适用条目记录 `Yes` / `No` / `Unclear` / `Not applicable`、简要理由和原文定位。定位尽量包含 PDF 页码、章节/表格/图号或可复核的段落标题；网页资料记录标题和链接，摘要记录数据库标识及摘要字段。找不到原文定位时明确标注，不能伪造精确引用。

每篇来源同时记录 `access_status` 和 `appraisal_sufficiency`。访问状态描述拿到的材料（如全文、摘要、注册记录、补充资料或无法获取）；评价充分性说明现有材料能否回答所需条目。可以对摘要中可观察的事实做有限评价，但不可观察的条目标为 `Unclear` / 待核实，不能因摘要未提及而判为 `Yes`，也不能仅因全文不可得就将整篇研究判为低质量。若评价充分性不足以支持整体判断，总体符号留空并列出缺失信息。

建议的评价状态为：`not_assessed`（尚未开始）、`in_progress`（逐项进行中）、`preliminary`（基于有限资料或快速流程的初步结果）、`complete_ai`（AI 按已核定规则完成逐项评价）、`complete_human_reviewed`（具名人员实际复核了所标明的范围）。记录评价者、日期、复核者、复核日期及复核范围；没有真实人工复核不得使用人工复核状态。多个模型或 Agent 的输出不构成人工复核。

只有适用表单、版本和总体汇总规则已经核对，且规则要求的条目和材料均充分时，才可输出完整 QCC 总体符号。规则未核定、关键条目缺失或评价充分性不够时，保留逐项记录和理由，`overall_symbol=null`，并说明“方法规则待核定”或具体缺失原因。不得按 Yes 数量猜测总体符号；不得把快速核查包装为完整 QCC。

### 当前用户匹配度

单独比较当前用户与证据在以下方面的相似性：

- 人群、诊断和基线营养或疾病状态；
- 干预的剂型、剂量、原料、配方与共干预；
- 对照条件；
- 用户真正关心的结局和研究测量的结局；
- 随访时长和使用情境。

使用“高 / 中 / 低 / 未知”等直观描述，并指出决定匹配度的具体信息。用户不匹配会降低当前问题的直接性或适用性，但不能反向改写原研究的方法学质量。

### 决策价值

另外评价：

- 效应是否达到用户能感知或临床重要的程度；
- 获益是否大于危害、不便和成本；
- 是否只在缺乏者或特殊人群中成立；
- 有无更可靠、更便宜或更直接的替代路径；
- 在用户现实约束下，补充措施能否触及主要问题。

决策价值不是“证据确定性”的同义词。群体证据低或极低时，先区分“可能有小获益但不确定”“尚不足以判断”“证据显示无重要效果”和“证据提示有害”。只有前两类才可继续读取 `bounded-self-trial.md`，评估低风险结构化个体试用；后两类不能用“个体差异”改写成正向建议。

若采用个体试用，仍分别报告群体证据确定性、当前用户匹配度和试用的决策价值。个人结果不回填为更高的群体证据等级。

### 给普通用户的组合表达

优先使用这样的结构：

> 对【研究人群】的【结局】，证据体确定性为【等级】；根据证据生成前收集的信息，你与该人群的匹配度为【匹配度】，仍不确定的是【少量关键项目】；即使适用，预计收益为【量级】，因此决策价值为【判断】。

不要说“因为不知道你的年龄，所以这篇论文证据等级低”。

## 4. 冲突裁决而非来源堆砌

展开层的目标是说明为什么看似矛盾的来源不应获得相同权重。比较时至少记录：来源角色及结论、PICOS 或检索时间差异、决定可信度的方法局限、对本次决策的权重。权重不得仅由期刊名、影响因子、研究设计标签或商业资助单独决定。

冲突裁决的输入必须来自预定义检索和筛选形成的证据体。通用网页搜索、搜索引擎“最相关”排序、挑选支持与反对各一篇论文，均不能证明已经覆盖冲突来源；这些方法只能用于发现候选词、指南或综述。普通功效问题按 `rapid-audit.md` 保存 PubMed 全量导出和筛选记录后再裁决。

若来源并不真正冲突，不要为了形成戏剧性叙事而制造对立；说明证据在哪些结局上一致、剩余不确定性在哪里即可。

## 5. 指南冲突分类

| 类型 | 表现 | 处理 |
|---|---|---|
| 表面冲突 | 人群、剂量、结局或用途不同 | 分别说明各自成立范围，不做完整 Meta |
| 时间冲突 | 新指南纳入了旧指南之后的新研究 | 以更新证据为主，同时评价新指南质量 |
| 推荐冲突 | 证据相近，但价值、成本或阈值不同 | 展示证据共识和决策差异 |
| 方法冲突 | 检索、偏倚评价或合并方法不同 | 比较方法可信度，必要时专业审计 |
| 真正证据冲突 | 近似同一 PICOS 的可信来源仍结论相反 | 建议研究级检索或新的证据合成 |

若冲突来源采用不同评价框架，应保留并标注各自原始评级及范围；本 Skill 按 EAL 工作流独立评价当前证据体，不在框架间换算等级。快速流程的简化必须披露；无法判断的项目不能默认为无问题。
